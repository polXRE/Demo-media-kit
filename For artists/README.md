# Raga Echoes Artist Media Kits

Static GitHub Pages-ready website for the Raga Echoes artist media kits page.

## Deploy on GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository, or publish this folder as the site source.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the branch and `/ (root)` folder, then save.
4. Open the generated Pages URL. `index.html` is the site entry point.

The embedded artist media kit preview and all local image assets are included in this folder.
