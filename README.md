# Ananya Sharma EPK

Static, GitHub Pages-ready electronic press kit. The page is served directly from `index.html`; no package installation or build step is required.

## Files

- `index.html` — page structure, styling, and interactions.
- `assets/images/` — optimized WebP logo and photography, loaded with relative URLs.

The photo files preserve their source pixel dimensions and use WebP quality 90; the transparent logo is saved losslessly. The original files outside this `push` folder are unchanged.

## Publish with GitHub Pages

1. Put the contents of this folder (`index.html`, `assets/`, and this README) at the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch and `/ (root)`, and save.
4. Open the Pages URL shown in the settings after the deployment completes.

Google Fonts and Font Awesome remain external CDN resources; the page and photography are hosted from this repository.
